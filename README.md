The Bank Management System is a console-based application developed in C that manages customer banking records and transactions.
The project uses Structures to represent account data, Singly Linked Lists (SLL) for dynamic record management, and File Handling
for persistent storage of customer information.
Additional concepts such as Pointers, Dynamic Memory Allocation, and Functions are used to implement efficient account operations including
account creation, deposits, withdrawals, balance inquiries, account updates, and account deletions. The application is developed using the
GCC Compiler on Ubuntu Linux with Visual Studio Code (VS Code) as the development environment. Git and GitHub are used for version control 
and source code management.
